# Unit 1 — Introduction to Deep Reinforcement Learning

This directory contains the practical exercises and experiments completed
during Unit 1 of the Hugging Face Deep Reinforcement Learning Course.

## Overview

This unit introduces the fundamental concepts of reinforcement learning
and demonstrates how agents learn through interaction with an environment.

## Learning Objectives

- Understand agents, environments, states, actions, and rewards.
- Distinguish between episodic and continuing tasks.
- Understand the exploration-exploitation trade-off.
- Learn the difference between value-based and policy-based methods.
- Understand the basic reinforcement learning training process.
- Train and evaluate a reinforcement learning agent.

## Practical Exercise — LunarLander

The practical exercise involves training a reinforcement learning agent
to land a spacecraft safely in the LunarLander environment.

**Environment:** LunarLander-v3  
**Algorithm:** Proximal Policy Optimization (PPO)  
**Framework:** Stable-Baselines3  
**Training Platform:** Google Colab

## Results

Training results, evaluation metrics, and visualisations
will be added after completing the practical exercise.
