# Deep Reinforcement Learning — Hugging Face Course

Implementations, exercises, and experiments completed as part of the [Hugging Face Deep Reinforcement Learning Course](https://huggingface.co/learn/deep-rl-course/en/unit0/introduction).

This repository documents my progress in learning Deep Reinforcement Learning (Deep RL), covering fundamental concepts, value-based methods, policy-based algorithms, and practical applications using reinforcement learning environments.

The objective is to develop a strong understanding of reinforcement learning algorithms through hands-on implementations, model training, evaluation, and experimentation.

---

## Learning Objectives

The main objectives of this course are to:

- Understand the fundamental concepts of reinforcement learning.
- Explore Markov Decision Processes (MDPs), rewards, policies, and value functions.
- Implement value-based reinforcement learning algorithms.
- Understand Deep Q-Networks (DQN) and policy gradient methods.
- Explore actor-critic architectures and Proximal Policy Optimization (PPO).
- Train and evaluate reinforcement learning agents in simulated environments.
- Analyse training performance, learning behaviour, and algorithm limitations.

## Technologies and Tools

The following technologies will be used throughout the course:

- **Python** — Programming language for reinforcement learning implementations.
- **PyTorch** — Deep learning framework for neural network models.
- **Gymnasium** — Reinforcement learning environments and evaluation.
- **Stable-Baselines3** — Implementations of reinforcement learning algorithms.
- **NumPy** — Numerical computations and data processing.
- **Matplotlib** — Visualisation of training results and performance.
- **Google Colab** — Cloud-based environment for practical exercises.
- **Hugging Face Hub** — Model sharing and evaluation.

Additional libraries and tools may be introduced as the course progresses.
